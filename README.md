# Shelfie

**Социальная медиа-платформа и каталог рецензий медиа-контента** — единый учёт книг, фильмов и сериалов: полки, оценки, рецензии, подписки и оформленные подборки-витрины.

## О проекте

Пользователь ведёт один аккаунт вместо Letterboxd + Goodreads: отмечает статус («Читаю/Смотрю», «Просмотрено/Прочитано», «Запланировано», «Брошено»), ставит оценки, пишет рецензии и комментарии, подписывается на других и видит ленту активности. Каталог наполняется из внешних источников (TMDB, OpenLibrary, Google Books) с кэшем в собственной БД и дополняется локальными карточками кыргызских фильмов и книг, которые подтверждает модератор. Отдельная фишка — публичные списки-витрины с личными заметками и темами оформления.

Полное техническое задание: [`docs/tz/tz.md`](docs/tz/tz.md) (исходник — [`docs/tz/ТЗ_ТКРПО.docx`](docs/tz/ТЗ_ТКРПО.docx)).

## Быстрый старт

### Вариант 1 — всё в Docker (как в ТЗ)

```bash
cp .env.example .env      # Windows: copy .env.example .env
docker compose up --build
```

- фронтенд — http://localhost:5173
- API и Swagger — http://localhost:8000/docs
- health-check — http://localhost:8000/api/health

### Вариант 2 — локально, без Docker

```bash
# backend
cd backend
python -m venv .venv
.venv\Scripts\activate          # Linux/macOS: source .venv/bin/activate
pip install -e ".[dev]"
uvicorn app.main:app --reload   # http://localhost:8000

# frontend (второй терминал)
cd frontend
npm install
npm run dev                     # http://localhost:5173
```

Подробности и переменные окружения — в [`CONTRIBUTING.md`](CONTRIBUTING.md).

## Как мы работаем

1. Берём задачу из [`tasks/board.md`](tasks/board.md), переводим её в `in progress`.
2. Ветка `feat/T<этап>.<номер>-короткое-имя`, коммиты в стиле Conventional Commits.
3. PR в `main` с описанием по шаблону → ревью второго участника → squash-merge.
4. `main` всегда зелёный: тесты и линтеры проходят.

Правила веток, коммитов, миграций и ревью — [`docs/git-workflow.md`](docs/git-workflow.md).
