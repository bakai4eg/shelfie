## Что нужно получить

Система различает пользователя, модератора и администратора, и каждый видит только своё.

## Бэкенд

- [ ] Роль в `users.role` (`user` / `moderator` / `admin`), иерархия уровней.
- [ ] Зависимости `require_moderator`, `require_admin`, 403 с понятным текстом.
- [ ] Скрипт выдачи роли для разработки (`python -m app.scripts.set_role`).
- [ ] Тест-матрица доступа по всем защищённым маршрутам.

## Фронтенд

- [ ] Скрытие админ-разделов в навигации по роли.
- [ ] Экран 403 («Недостаточно прав») вместо белого экрана.

## Приёмка

- [ ] Модератор открывает `/moderation`, обычный пользователь получает 403.
- [ ] Роль из токена не подделывается: сервер берёт её из БД.
- [ ] Есть тест на каждый уровень доступа.

## Заметки

Проверку прав делаем зависимостью маршрута, а не `if` внутри обработчика.
