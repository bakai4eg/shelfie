## Что нужно получить

Пользователь сам управляет своим профилем: описание, аватар и пароль.

## Бэкенд

- [x] `PATCH /me/profile` — `bio` до 500 символов.
- [x] `POST /me/avatar` — загрузка файла (jpg/png/webp, лимит из `MAX_UPLOAD_SIZE_MB`), `DELETE /me/avatar`; при замене старый файл удаляется с диска.
- [x] `PUT /me/password` — проверка текущего пароля, отзыв всех сессий после смены.

## Фронтенд

- [x] Страница `/settings` с тремя блоками: описание, аватар, пароль.
- [x] Превью аватара и кнопка удаления, счётчик символов у описания.
- [x] После смены пароля — принудительный выход с сообщением «Войдите заново».

## Приёмка

- [x] Новый аватар появляется в профиле и в шапке сайта.
- [x] Файл больше лимита или неверного типа отклоняется с понятной ошибкой (422).
- [x] После смены пароля старый токен даёт 401, вход с новым паролем работает.
