## Что нужно получить

Один каталог для книг, фильмов и сериалов: поиск по названию, фильтры, сортировка и региональный фильтр «Кыргызстан».

## Бэкенд

- [x] Модель `catalog_items` + индексы (`type`, `year`, `is_local`, `title_normalized`, `source/external_id`).
- [x] `GET /catalog`: `q`, `type`, `year_from/to`, `genre`, `country`, `source`, `local_only`, `sort`, пагинация.
- [x] `GET /catalog/filters` — значения для панели фильтров.
- [x] Видимость: `approved` всем, свои `pending` — автору (и модераторам), `hidden` — никому.

## Фронтенд

- [x] Страница `/catalog`: поиск с debounce, панель фильтров, сетка карточек, пагинация.
- [x] Фильтры сохраняются в URL (можно поделиться ссылкой) и сбрасываются одной кнопкой.
- [x] Пустой результат объясняет, что делать («Попробуйте изменить фильтры или создайте карточку»).

## Приёмка

- [x] Поиск «Манас» и «Inception» возвращает релевантные карточки нужного типа.
- [x] Комбинация фильтров (тип + год + страна) не противоречит сама себе и отражается в URL.
- [x] `local_only=true` оставляет только карточки с `is_local = true`.

## Заметки

Пока внешних источников нет (T2.2) — каталог работает на локальных и засеянных данных. Сиды: `backend/app/db/seed.py`.

Миграция `0002_catalog_items`, сервис `app/services/catalog.py`, 11 тестов в `tests/test_catalog.py`. Поиск идёт по `title_normalized` (lower от названия и оригинального), потому что SQLite не умеет `lower()` для кириллицы. `rating_avg` расширен до `numeric(4,2)`: средняя 10.00 не влезала в `(3,2)`.
