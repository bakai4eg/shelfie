## Что нужно получить

Один каталог для книг, фильмов и сериалов: поиск по названию, фильтры, сортировка и региональный фильтр «Кыргызстан».

## Бэкенд

- [ ] Модель `catalog_items` + индексы (`type`, `year`, `lower(title)`, `is_local`).
- [ ] `GET /catalog`: `q`, `type`, `year_from/to`, `genre`, `country`, `source`, `local_only`, `sort`, пагинация.
- [ ] `GET /catalog/filters` — значения для панели фильтров.
- [ ] Видимость: `approved` всем, свои `pending` — автору, `hidden` — никому.

## Фронтенд

- [ ] Страница `/catalog`: поиск с debounce, панель фильтров, сетка карточек, пагинация.
- [ ] Фильтры сохраняются в URL (можно поделиться ссылкой) и сбрасываются одной кнопкой.
- [ ] Пустой результат объясняет, что делать («Попробуйте изменить фильтры или создайте карточку»).

## Приёмка

- [ ] Поиск «Манас» и «Inception» возвращает релевантные карточки нужного типа.
- [ ] Комбинация фильтров (тип + год + страна) не противоречит сама себе и отражается в URL.
- [ ] `local_only=true` оставляет только карточки с `is_local = true`.

## Заметки

Пока внешних источников нет (T2.2) — каталог работает на локальных и засеянных данных. Сиды: `backend/app/db/seed.py`.
