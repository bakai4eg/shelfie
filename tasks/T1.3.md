## Что нужно получить

У каждого пользователя есть публичная страница с логином в адресе, аватаркой, описанием и честной статистикой.

## Бэкенд

- [ ] `GET /users/{login}`: профиль + статистика (книги, фильмы, сериалы, оценки, средняя оценка, рецензии, подписчики, подписки).
- [ ] `GET /users/{login}/reviews` и `/lists` — публичные разделы профиля.
- [ ] Статистика пересчитывается при изменении статуса или оценки, а не «раз в сутки».

## Фронтенд

- [ ] Страница `/u/:login`: шапка профиля, блок статистики, рецензии и публичные списки.
- [ ] Пустые состояния («Пока нет рецензий») и скелетоны на время загрузки.
- [ ] Своя страница отличается действием «Редактировать профиль».

## Приёмка

- [ ] Страница открывается в режиме инкогнито по `/u/<login>`.
- [ ] После смены статуса на «Просмотрено» число в статистике меняется без ручного обновления.
- [ ] Средняя оценка считается только по выставленным оценкам, деления на ноль нет.

## Заметки

Подписки появятся в T5.4, полки — в T2.4, поэтому на этапе 1 статистика по книгам, фильмам, сериалам и подпискам отдаёт нули: поля уже в контракте, а считаем их из таблиц, когда те появятся. Это не блокер для сдачи этапа.
