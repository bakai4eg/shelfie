## Что нужно получить

Сообщество добавляет кыргызские фильмы и книги, которых нет в международных каталогах, а модератор это подтверждает.

## Бэкенд

- [x] `POST /cards/local` — тип, название, оригинальное название, год, страна, жанры, описание, обложка, `is_local`.
- [x] `source = local`, `moderation_status = pending`; видна автору и модераторам.
- [x] `GET /cards/local/duplicates?title=&year=` — подсказки перед созданием.
- [x] `GET /cards/local/mine`, `PATCH /cards/local/{id}` пока карточка `pending`.

## Фронтенд

- [x] Форма создания карточки, в том числе с телефона (от 360 px).
- [x] Проверка совпадений до отправки: «Похоже, такая карточка уже есть».
- [x] Раздел «Мои карточки» со статусом проверки и возможностью поправить.

## Приёмка

- [x] Созданная карточка не видна гостю, но видна автору.
- [x] Обложка загружается и отображается в списке «Мои карточки».
- [x] Совпадение по названию и году предлагается до сохранения.

## Реализация

- `backend/app/api/routes/cards.py`, `services/catalog.py`, `core/media.py`;
  тесты — `tests/test_local_cards.py`.
- Обложки лежат в `MEDIA_ROOT/posters`, в БД хранится относительный путь.
- Фронтенд: `/my/cards`, `/cards/new`, `/cards/:itemId/edit`.

## Заметки

Подтверждение модератором — в T4.2, здесь только статус `pending` и видимость.
