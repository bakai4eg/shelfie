## Что нужно получить

Пользователь собирает оформленную подборку, добавляет личные заметки и публикует её отдельной страницей.

## Бэкенд

- [x] Модели `lists` / `list_items`: название, описание, приватность, `position`, `note` ≤ 500, тема.
- [x] CRUD списков, добавление/удаление позиций, `PUT /me/lists/{id}/order`.
- [x] Публичный `GET /public/lists/{id}` — только для `is_public`, иначе 404.
- [x] Темы: минимум три (`classic`, `noir`, `pastel`).

## Фронтенд

- [x] Раздел `/me/lists` и редактор списка: drag&drop порядка, заметка к каждой позиции, выбор темы.
- [x] Публичная витрина `/lists/:id` с обложками, заметками и выбранной темой; адаптив от 360 px.
- [x] Кнопка «Поделиться» копирует постоянную ссылку.

## Приёмка

- [x] Порядок карточек сохраняется после перезагрузки.
- [x] Заметка длиннее 500 символов не сохраняется и подсвечивается.
- [x] Приватный список по публичной ссылке даёт 404.
- [x] Все три темы визуально различаются, а не только называются по-разному.

## Заметки

Список — главная фишка проекта: не экономим на витрине и проверяем её на телефоне.
