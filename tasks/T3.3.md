## Что нужно получить

Пользователь ставит, меняет и снимает оценку, а карточка показывает честный средний балл.

## Бэкенд

- [x] `PUT /me/ratings/{item_id}` (1–10) и `DELETE /me/ratings/{item_id}`.
- [x] Пересчёт `rating_avg` и `ratings_count` в той же транзакции.
- [x] Для `planned` оценка не запрашивается; оценка без статуса сохраняется.
- [x] Тест: идемпотентность, снятие оценки, отсутствие расхождений агрегатов.

## Фронтенд

- [x] Шкала оценки на карточке и в форме рецензии (10 звёзд или ползунок — решаем по макету).
- [x] Средний рейтинг и число оценок видны в каталоге и на странице карточки.
- [x] Снятие оценки возвращает состояние «Оценить».

## Приёмка

- [x] Оценка 8 меняет средний балл сразу, без перезагрузки.
- [x] Повторная оценка тем же значением не создаёт дубль.
- [x] Средний рейтинг пустой карточки — 0 или «нет оценок», без NaN.

## Заметки

Денормализованные поля обязательны — иначе каталог начнёт тормозить на подсчётах.
