## Что нужно получить

Пользователь отмечает, что читает/смотрит, что завершил, что планирует и что бросил — и видит это полками.

## Бэкенд

- [ ] Модель `user_items`: `status`, `finished_at`, `added_at`, `unique(user_id, item_id)`.
- [ ] `PUT /me/library/{item_id}`, `DELETE /me/library/{item_id}`, `GET /me/library` с фильтром по типу и сортировкой (дата, оценка, название).
- [ ] Правила: `finished_at` обязателен для `finished` и редактируется; для остальных статусов — `null`.

## Фронтенд

- [ ] Блок кнопок статуса на карточке контента с текущим состоянием.
- [ ] Страница `/me/library`: табы по статусам, фильтр по типу, сортировка, пустые состояния.
- [ ] Дата завершения: подстановка сегодняшней и возможность изменить.

## Приёмка

- [ ] Смена статуса видна сразу после ответа API и сохраняется после перезагрузки.
- [ ] Убрать с полки можно в один клик с подтверждением.
- [ ] Сортировка «по оценке» не падает, если оценок нет.

## Заметки

Оценка появится в T3.3 — колонку `rating` заводим сразу, UI оценки подключаем позже.
