## Что нужно получить

Пользователь отмечает, что читает/смотрит, что завершил, что планирует и что бросил — и видит это полками.

## Бэкенд

- [x] Модель полки (`shelf_entries`): `status`, `finished_at`, `created_at` (дата добавления), `unique(user_id, item_id)`.
- [x] `PUT /me/library/{item_id}`, `DELETE /me/library/{item_id}`, `GET /me/library` с фильтром по типу и сортировкой (дата, оценка, название).
- [x] Правила: `finished_at` обязателен для `finished` и редактируется; для остальных статусов — `null`.

## Фронтенд

- [x] Блок кнопок статуса на карточке контента с текущим состоянием.
- [x] Страница `/me/library`: табы по статусам, фильтр по типу, сортировка, пустые состояния.
- [x] Дата завершения: подстановка сегодняшней и возможность изменить.

## Приёмка

- [x] Смена статуса видна сразу после ответа API и сохраняется после перезагрузки.
- [x] Убрать с полки можно в один клик с подтверждением.
- [x] Сортировка «по оценке» не падает, если оценок нет.

## Заметки

Оценка хранится в отдельной таблице `ratings` (T3.3), полка получает её через `user_rating`
в ответе `GET /me/library` — так оценка живёт независимо от статуса полки.

## Реализация

- Бэкенд: `models/library.py`, `services/library.py`, `api/routes/library.py`
  (был готов в рамках T1.3/T3.3, здесь проверен и покрыт тестами).
- Тесты: `tests/test_library.py` — фильтры, сортировки без оценок, правка даты, 404.
- Фронтенд: `pages/LibraryPage.tsx`, блок полки в `pages/ItemPage.tsx`, ссылка «Мои полки» в шапке.
