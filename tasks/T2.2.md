## Что нужно получить

Каталог сам наполняется из внешних источников, переживает их недоступность и не долбит API на каждый запрос.

## Бэкенд

- [ ] Клиенты `services/providers/{tmdb,openlibrary,google_books}.py` на `httpx.AsyncClient`.
- [ ] Нормализация ответов в общий вид карточки, дедупликация по `(source, external_id)`.
- [ ] Сохранение в БД с `fetched_at`; TTL из `CACHE_TTL_DAYS`; повторные запросы из БД.
- [ ] Отказоустойчивость: таймаут/5xx источника → пропускаем источник, отдаём остальное, пишем warning.
- [ ] Тесты на моках: успех, таймаут, пустой ответ, повторный запрос из кэша.

## Фронтенд

- [ ] Бейдж источника на карточке в каталоге и на странице карточки.
- [ ] Мягкое предупреждение «Часть источников недоступна» вместо пустого экрана.

## Приёмка

- [ ] Первый поиск фильма обращается к TMDB, повторный — только к БД (проверяем по логам).
- [ ] С выключенной сетью поиск всё равно отдаёт сохранённые ранее результаты.
- [ ] Ключи читаются из `.env`, в репозиторий не попадают.

## Заметки

Ключ TMDB и Google Books нужен заранее — заведите и положите в локальный `.env`, не в git.
